# Employee Dashboard

A React-based Employee Dashboard created as part of a JavaScript/React assignment.

## Features

- React-based Employee Dashboard
- Navbar with Home and Employee Form links
- Employee data fetched from JSONPlaceholder API
- Employee data displayed in a table
- Displays employee ID, name and email
- Employee form with Name, Designation, Location and Salary
- React Router for navigation
- Bootstrap for styling
- Form data is not posted to an external API

## API Used

https://jsonplaceholder.typicode.com/users

## Technologies Used

- React
- Vite
- React Router
- Bootstrap
- JavaScript
